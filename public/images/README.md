# Images

Ce dossier contient les images utilisées dans le portfolio.

## Images requises

- `profile.jpg` : Votre photo de profil (200x200px recommandé)
- `ecommerce.jpg` : Image du projet e-commerce
- `task-manager.jpg` : Image du projet gestionnaire de tâches
- `weather-app.jpg` : Image du projet météo
- `placeholder.jpg` : Image par défaut pour les projets sans image

## Recommandations

- Format : JPG, PNG ou WebP
- Taille recommandée pour les projets : 800x600px
- Optimisez vos images avant de les ajouter (utilisez TinyPNG ou similaire)
- Utilisez des noms de fichiers descriptifs

## Sources d'images gratuites

Si vous avez besoin d'images temporaires :
- [Unsplash](https://unsplash.com)
- [Pexels](https://pexels.com)
- [Pixabay](https://pixabay.com)
